Set 9

Machines, not dials

Set 8 modelled generators as numbers between zero and their rating. Set 9 models them as equipment that has a minimum output, takes time to move, and cannot be switched on and off for free — and re-runs the whole question.

Set 9 · machines, not dials
FramingSet 9 is a robustness test of Set 8, not a replacement. The question is whether the Set 8 finding survives once the generators behave like real equipment.

The gap

Set 8 described 24 power stations with one line of code

# Set 8, cases.jl
@variable(m, 0 <= P[g in G] <= case.pmax[g])

What that permits

  • A 128 MW steam unit idling at 3 MW
  • Going from 0 to full output in one hour
  • Starting and stopping every hour, free

What real equipment does

  • Has a minimum stable output below which it trips
  • Changes output at a bounded rate
  • Costs money and hours to start from cold

Why this needed a new experiment

You cannot bolt a ramp limit onto Set 8

A ramp constraint compares hour t with hour t−1. Set 8 sampled hours independently, with replacement — hour 5,000 could follow hour 12. There was no previous hour to compare against.

Set 8

10,000 unordered snapshots. Each one a separate question: can the grid serve this hour?

Set 9

8,760 hours in order, solved as 24-hour blocks with commitment state carried across every boundary. One continuous question: can the grid run this year?

That is a different experimental design, which is why Set 9 generates all of its own numbers and reuses none of Set 8's. Results from two different models are not comparable, and Set 8's own finding is exactly about the danger of pretending otherwise.

The design

Two demand worlds, four constraint rungs, eight fresh runs

One change per rung, on purpose

Each rung adds exactly one constraint, so every movement in the results is attributable to a named cause. Jumping straight to the fully constrained model would produce a number nobody could decompose — which is the mistake Set 8 spent eighteen pages warning about.

The number that matters for Set 9

The exponential world demands the fleet move 428.9 MW between consecutive hours on average, against a real record that moves 41.9. Ten times. That is a question about machines, and Set 8 had no way to ask it.

How hard each cell was to solve is itself a result

Real load at Set 8's constraint set solved in 10 seconds. The exponential world fully constrained took 39 minutes, and 46 of its 365 daily blocks hit the time cap. The fleet is being asked to follow demand it physically cannot, so the solver must search an enormous space of which customers to cut off and when. Difficulty of solution is evidence about the demand model.

Finding one

The Set 8 conclusion survives the physics

0.45%

real load — hours needing customers cut off, fully constrained fleet

26.7%

assumed exponential — same grid, same solver, same mean demand, same constraints

And it holds at every rung

Adding minimum stable generation, ramp limits, minimum up and down times and start-up costs does not close the gap — it widens it. Fully constrained, the assumed distribution produces a blackout risk 59 times the one real load produces.

Measured in energy rather than hours the gap is starker still: 705,776 MWh not served against 29 MWh.

Set 8's central claim was not an artefact of an over-simplified generator model.

Finding two · new

A failure mode Set 8 could not see

0.58%

of hours under real load where the grid must cut customers off — once ramp limits exist. About 51 hours a year.

Not a capacity problem. A following problem.

Set 8 reported zero shedding under real load, and that was correct for the question it asked: there is always enough capacity.

But capacity is not the same as reachability in time. On a handful of evenings the island's load climbs faster than the committed fleet can follow, and the shortfall is real even though the megawatts exist.

Set 8 could not detect this, because its hours had no order.

Finding three · the uncomfortable one

The congestion number is not robust

Same demand. Same network. Same year. Only the generator constraint set changed:

Why, and what it means

Commitment decides which units run and therefore where power enters the network — and that changes the flows. Set 8's model could spread output thinly across all 24 units; a committed fleet cannot.

So the honest statement is: the direction is robust, the magnitude is not. Real load congests more than exponential load at every rung. But a congestion percentage should never be quoted without the commitment model beside it.

Do not hide thisIt partly undercuts a Set 8 headline, and reporting it is the right call. Note the structure: it is Set 8's own lesson applied one level up — there, the demand assumption moved the answer; here, the commitment assumption does.

Methods · a bug worth reporting

The first version said real load sheds 95% of the year

It does not. That number was an artefact of the constraint formulation, and finding it is the reason the ladder design was worth the compute.

The trap

Every steam unit here has p_min = 40% of capacity but a ramp rate of 30% per hour.

Write the ramp limit the obvious way — |P[t] − P[t−1]| ≤ ramp — and starting up means jumping from 0 to p_min in one hour, which exceeds the ramp. Every steam unit becomes permanently unstartable.

The fix

Start-up and shut-down get their own ramp allowance, so a unit coming online arrives at its minimum output legitimately. Standard in the literature; easy to omit.

The tell was the model running expensive peakers around the clock while cheap steam sat idle — an answer that made no economic sense, which is usually how a formulation error announces itself.

Still not fixed

What Set 9 does not answer

Per-bus demand is reconstructed, not meteredThe filed profile is island-total only. The v3 rebuild does make the mix move hour to hour — Honolulu runs about 52% at midnight to 85% at midday — but it is built from typical-year reference-building shapes, not Oʻahu’s metered sector loads. The direction moves; whether it moves correctly is unverified.
No forced outagesEvery unit is assumed always available. For an adequacy study this remains the largest single gap.
No N−1 securityOn an island with no imports, surviving the loss of the largest unit is the real planning constraint.
No storage, no reservesKapolei-scale batteries would absorb exactly the ramp events Finding Two identifies.
Still DC power flowNo voltage, no reactive power, no losses.

In closing

Three sentences

One — the reassurance

Set 8's finding was not an artefact of treating generators as dials. The gap between assumed and real demand survives every constraint we added.

Two — the new risk

Real load out-runs the committed fleet in about 51 hours a year — a shortfall of speed, not capacity, and the earlier model was blind to it. It is small: 37 MWh across the year. It is not zero.

Three — the caution

Congestion frequency moved 39 points across constraint sets on identical demand. The direction is robust; the number is not. Never quote one without saying which generator model produced it.
